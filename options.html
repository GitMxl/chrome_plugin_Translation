让翻译留在你的设备上

在网页选择文字，点击「译」。默认通过 WebGPU 在本机推理，无需密钥。

翻译偏好

API 模式会把选中文字发送到下面的服务。API 密钥仅保存在当前扩展的本地存储。

整页双语翻译

切换到需要翻译的网页后点击扩展图标，或使用网页右键菜单「翻译整页」。正文逐段翻译，原文保留，网页右下角显示进度。跳过表单、代码及隐藏内容；整页段落不逐条写入翻译历史。
